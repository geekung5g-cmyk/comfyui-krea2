โมเดลที่มีอยู่

Civitai API Key

สร้างที่ civitai.com → Account → API Keys · จำเป็นสำหรับโมเดลส่วนใหญ่

Hugging Face Token

สร้างที่ huggingface.co → Settings → Access Tokens (สิทธิ์ read พอ) · จำเป็นเฉพาะ repo ที่ gated/private

คีย์ถูกเก็บไว้ที่ไหน
